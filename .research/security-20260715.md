# Security Review — Issue #6 / #7

Reviewed: `master` vs working tree | Findings: critical 0 / high 0 / medium 0 / low 2

The changes satisfy the acceptance criteria for Issues #6 and #7. Presigned uploads no longer receive Notion credentials, and all authenticated API methods reject absolute, protocol-relative, and backslash-authority URLs before sending.

## [LOW] A10:2021 SSRF — `src/api/files.rs:50`

The presigned upload URL is not restricted to HTTPS or known upload hosts. Exploitation requires a modified or compromised Notion API response, but an abnormal URL could send file contents to loopback, a private network, or plaintext HTTP.

**Fix:** Require HTTPS, consider an allowlist for documented Notion upload hosts, and validate redirect targets or disable redirects.

## [LOW] A02:2021 Cryptographic Failures — `src/client/request.rs:95`

The initial API URL is origin-checked, but reqwest redirects remain enabled. A compromised upstream could redirect from HTTPS to HTTP on the same host and effective port without reqwest removing the Authorization header.

**Fix:** Disable redirects for authenticated API requests, or only follow redirects whose scheme is HTTPS and whose origin exactly matches the initial URL.
